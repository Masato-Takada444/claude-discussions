# Claude Discussions

This directory contains discussion logs generated by Claude Code's `/discuss-with-gemini` command.

## Structure

```
claude-discussions/
├── YYYYMM/           # Year and month
│   └── gemini_discussion_YYYYMMDD_HHMMSS.md
```

## Usage

Use the `/discuss-with-gemini` command in Claude Code to start a structured discussion with Gemini about:
- Requirements analysis
- Architecture decisions
- Implementation strategies
- Technical problem-solving

## Note

These files are gitignored by default as they contain working discussions that may not be relevant to the repository's main content.
