# 5. 出力フォーマット

## 決定事項

### 出力CSV形式
- **方式**: 元のCSVに監査結果列を追加する形式

### 元データ列（全て保持）
- 支払先訪問先
- 目的
- メモ
- 経費科目名
- 出発地
- 到着地
- 税込金額
- 申請日
- 利用日
- 借方勘定科目
- 自社参加人数
- 他社参加人数
- 申請者名
- 社員番号
- 所属部署
- 役職
- 最終承認日
- 申請ID
- 借方税区分
- 借方税率
- 貸方勘定科目
- 税抜金額
- 消費税額
- 訪問先

### 追加する監査結果列
- タクシー判定結果
- タクシー判定理由
- アルコール判定結果
- アルコール判定理由
- 重複判定結果
- 重複判定理由
- 総合リスクレベル

## 設計上の考慮点
- 列名に判定結果の候補（高/中/低など）は含めない
- 将来的な判定ロジックの変更に対応しやすい設計
- 監査実行日時はファイル名に含める（例：expense_audit_20250107_143000.csv）
