# 10. 技術的制約

## 決定事項

### 使用技術
- **フロントエンド**: React/Next.js（検討中）
- **バックエンド**: Ruby on Rails
- **監査ロジック**: mastraでのワークフロー実装を検討
  - ワークフロー部分の記述しやすさを評価予定

### インフラ・環境
- **ファイルストレージ**: AWS S3
  - 入力・出力CSVの保存
  - 5年間の長期保存対応
- **インフラ管理**: Terraform
  - Infrastructure as Codeによる管理
- **認証基盤**: OAuth2
  - tokium-agent-travelと共通の仕組みを使用

### 設計方針
- tokium-agent-travelとの共通化は考慮しない
  - 両プロジェクトとも開発中のため独立して進める
- AWSインフラの共有は限定的
  - 必要に応じて部分的に共有

## 検討事項
- mastraを使用したワークフロー実装の評価
  - 監査ロジックの記述しやすさ
  - 保守性・拡張性の観点での適合性
