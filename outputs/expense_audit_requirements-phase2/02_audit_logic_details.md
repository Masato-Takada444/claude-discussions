# 経費監査システム - 監査ロジック詳細定義

## 1. アルコールが含む経費の検知

### 概要
飲酒が疑われる経費を対象に、支払先・科目・目的・メモ・曜日・参加人数など複数項目から、アルコールを含む支出かどうかをAIで判定する。

### 対象経費
借方勘定科目が以下のいずれか：
- 交際費
- 福利厚生費
- 会議費
- 消耗品費

### 監査インプット項目
- 経費ID
- 利用日
- 支払先訪問先
- 経費科目名
- 借方勘定科目
- 税込金額
- 自社参加人数
- 他社参加人数
- メモ
- 目的
- 申請日

### リスク判定基準
- **高リスク**: 明示的にアルコール関連と判断できる、または社会常識的に高確率で提供されると考えられる場合
- **中リスク**: 支払先訪問先がスーパー、コンビニの場合
- **低リスク**: アルコールが提供された可能性が極めて低い、または判断が困難である場合

### 判定ロジックの詳細
1. 支払先の特徴分析
   - 居酒屋・バーなど明らかにアルコール提供店：高リスク
   - スーパー・コンビニ：中リスク
   - 業務目的が明確な場合：中リスク

2. 経費科目・摘要の分析
   - 「懇親」「交流」「打ち上げ」「会食」「親睦」「顔合わせ」「お疲れ様会」：高リスク
   - あいまいで業務目的が不明確：中リスク

3. 利用時間帯・曜日
   - 金曜夜、土曜夜など飲酒が想定されるタイミング：高リスク

4. 人数構成と科目の不整合
   - 自社参加人数4人以上かつ高額：高リスク
   - 他社参加なしで「接待交際費」：高リスク

### 使用技術
- AI: GPT-4o
- 判定結果を150文字以内で理由説明

### 判定例
- 中リスク：「支払先が「ライフ」というスーパーであり、アルコール飲料の購入が可能な場所であるため、アルコールを含む可能性がある。」
- 高リスク：「金曜夜の「魚民」での利用で、メモに「懇親会」とあり、自社参加人数が8名と多いため、アルコールを含む可能性が高い。」

## 2. タクシー料金水増し経費の検知

### 概要
タクシーの利用に関する経費申請について、出発地・到着地・金額・時間帯・目的の記載などをもとに、タクシー料金の妥当性をチェック。

### 対象経費
支払先訪問先、目的、メモ、経費科目名のいずれかに以下のキーワードが含まれる場合：
```
RIDE, DiDi, Uber, MOV, Tokyo Prime, Fluct, 日本交通, 東京無線, 
日の丸交通, 第一交通, MK, エムケイ, タクシー, ハイヤー, 
TAXI, Taxi, taxi, ＣＡＢ
```

### 監査インプット項目
- 経費ID
- 支払先訪問先
- 目的
- メモ
- 経費科目名
- 出発地
- 到着地
- 税込金額

### リスク判定基準
登録金額と相場金額の差額により判定：
- **低リスク**: 差額1,000円未満
- **中リスク**: 差額1,000円以上5,000円未満
- **高リスク**: 差額5,000円以上

### 判定ロジックの詳細
1. 出発地・到着地から緯度経度を取得（Google Maps API）
2. 距離（km）と所要時間（分）を算出
3. 都道府県別タクシー料金表に基づき相場を計算
   - 初乗り料金
   - 距離加算料金
   - 時間加算料金
4. 登録金額と相場金額を比較

### 料金計算例（東京都）
- 距離：3.4km、時間：900秒の場合
- 初乗り：1.052kmまで500円
- 加算距離：233mごとに100円 → (3400m - 1052m) ÷ 233 ≒ 10回 → 1000円
- 時間加算：900秒 ÷ 95秒 ≒ 9回 → 900円
- 合計：500 + 1000 + 900 = 2,400円（相場金額）

### 使用技術
- AI: GPT-4o
- Google Maps Distance Matrix API
- 全国タクシー料金表（スプレッドシート管理）

### 判定例
- 中リスク：「相場金額820円に対して登録金額が1,900円と1,080円高く、距離・時間からみても過剰請求の可能性があります。」
- 高リスク：「相場金額3,140円に対して登録金額が20,000円と大幅に高く、距離・時間からみても過剰請求の可能性が非常に高いです。」

### 注意事項
- 出発地・到着地はできるだけ具体的（駅名、ビル名）に記載が必要
- 渋滞時は高リスクと判定される可能性が高い
- タクシー料金表は定期的な更新が必要

## 3. 人またぎ重複経費の検知

### 概要
利用日、金額、申請者名から、当人の二重申請や領収書の使いまわしによる不正経費をチェックする。

### 対象経費
利用日と税込金額が一致する経費が2つ以上ある場合

### 監査インプット項目
- 経費ID
- 利用日
- 税込金額
- 申請者名
- 借方勘定科目

### リスク判定基準
1. **低リスク**: 同一申請者による重複
   - 本人の二重申請や領収書使いまわしの疑い

2. **中リスク**: 異なる申請者による重複（特定勘定科目）
   - 勘定科目に「交通」または「研修」を含む場合
   - 複数人が同じ交通機関を利用する可能性を考慮

3. **高リスク**: 異なる申請者による重複（その他勘定科目）
   - 交通費・研修費以外の勘定科目
   - 領収書の使いまわしの可能性が高い

### 判定ロジックの詳細
1. `利用日 + 税込金額`をキーとしてグルーピング
2. グループ内の件数が2件以上の場合に処理実行
3. 申請者名の一致/不一致を判定
4. 不一致の場合は勘定科目でリスクレベルを分類

### 使用技術
- プログラムコードによる処理（AI不使用）
- ハッシュマップによるグルーピング
- セットによる申請者のユニーク性チェック

### 判定例
- 低リスク：「同じ利用日・金額で、かつ申請者も同じのため、本人の重複申請の可能性があります。」
- 中リスク：「同じ利用日・金額で、かつ申請者が異なる経費データがあり、勘定科目が「旅費交通費」のため中リスクと判定しました。」
- 高リスク：「同じ利用日・金額で、かつ申請者が異なる経費データがあり、勘定科目が「接待交際費」のため高リスクと判定しました。」

### 今後の検討事項
- 中リスクと判断する勘定科目の精査（現在は「交通」「研修」のみ）
- 同一店舗での分割会計など、正当な重複パターンの除外ロジック
