# 8. セキュリティ要件

## 決定事項

### データ保持期間
- **入力・出力CSV**: 5年間（電子帳簿保存法対応）
  - 初期実装：通常のS3ストレージ
  - 後からライフサイクルポリシーでコスト最適化可能

### アクセス制御
- **Phase2**: 実行者本人のみがデータにアクセス可能
- **将来**: TOKIUM経費精算の権限（集計者・監査者）と連携可能な設計

### 通信とメール送信
- **通信**: HTTPS必須
- **メール送信**: 
  - 初期実装：通常のCSV添付
  - 将来オプション：
    - ダウンロードリンク方式（有効期限付き）
    - パスワード付きファイル送信

### 将来の履歴確認機能で保存すべきデータ
- 実行者（OAuth認証からのユーザー情報）
- 実行日時
- 送信先メールアドレス（複数）
- 入力ファイル（S3パス）
- 出力ファイル（S3パス）
- 監査ロジックのバージョン（現時点では不要）
