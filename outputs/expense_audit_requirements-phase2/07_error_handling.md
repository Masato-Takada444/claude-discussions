# 7. エラー処理

## 決定事項

### エラー処理方針
処理が開始できれば必ずCSVを返す（全行エラーでも）

### 1. 個別行のエラー（処理継続）
- その行の監査結果列に「エラー」を記載
- エラー理由を判定理由列に記載
- 他の行は通常通り処理を継続
- 全行がエラーになっても同じ形式でCSVを出力

#### 例
- タクシー判定結果：「エラー」
- タクシー判定理由：「出発地・到着地が未入力のため判定不可」

### 2. システムレベルのエラー（処理停止）
- CSVフォーマットエラーなど、そもそも処理が開始できない場合のみ
- CSVは作成せず、エラーメールを送信

#### エラー内容の例
- 「CSVフォーマットエラー：必須列[申請者名]が見つかりません」
- 「システムエラー：監査処理中に問題が発生しました」
