# アルコールが含む経費の検知

実装状況: 完了

## ■ロジック概要

<aside>
💡

このロジックが「何を」検知・監査しているか

飲酒が疑われる経費を対象に、支払先・科目・目的・メモ・曜日・参加人数など複数項目から、アルコールを含む支出かどうかをAIで判定する。

</aside>

## ■目的

<aside>
💡

なぜこの監査ロジックが必要なのか（不正抑止・内部統制・税務要件 など）

交際費・福利厚生費・会議費・消耗品費などに潜む私的な目的でのアルコール支出を検知するため。

</aside>

## ■対象経費

<aside>
💡

このロジックが適用される条件

借方勘定科目が「交際費」「福利厚生費」「会議費」「消耗品費」のいずれか

</aside>

## ■監査インプット項目

<aside>
💡

ロジックが参照する具体的なフィールド名とその内容

- 利用日
- 支払先訪問先
- 経費科目名
- 借方勘定科目
- 税込金額
- 自社参加人数
- 他社参加人数
- メモ
- 目的
</aside>

## ■監査ロジックの詳細

<aside>
💡

処理の流れ

1. Google Sheetsから対象の経費データを読み取り
2. 特定の借方勘定科目に合致する経費をフィルタリング
3. AIに経費のインプット項目を読み取らせ、プロンプトを送信してリスク判定
4. 判定結果を整形し、「アルコール判断」「理由（アルコール）」としてGoogle Sheetsに書き込み

💡　プロンプト

- アルコール検知プロンプト

    あなたは経費精算の監査担当者です。

    以下の経費データが **「アルコール飲料を含む可能性が高い支出」かどうか** を社会人経験と常識、そしてリスク観点に基づいて判断してください。

    単に「酒」「ビール」「懇親会」というキーワードが含まれているかだけでなく、以下の観点を総合的に考慮して、精度の高い判断をしてください。

    ---

    【1. 支払先に関する特徴】

    - 支払先訪問先から一般的にアルコール類の提供が想像できる場合：高リスク
    - 支払先訪問先が「スーパー」「コンビニ」の場合：中リスク
    - 支払先訪問先からアルコール類が絡む店なのかわからないが、【2】以降の記載が入力欄にある場合：高リスク
    - 支払先訪問先からアルコール類が絡む店なのかわからないが、業務目的であることがほかの入力データから推測できる場合：中リスク

    【2. 経費科目・摘要欄】

    - 経費科目が「接待交際費」「会議費」「打ち合わせ費」など、飲み会の言い換えが使われている可能性：高リスク
    - メモや目的欄に「懇親」「交流」「打ち上げ」「会食」「親睦」「顔合わせ」「お疲れ様会」などの語句が含まれる：高リスク
    - あいまいで業務目的が明確でない言い回しがある：中リスク

    【3. 利用時間帯・曜日】

    - 金曜夜、土曜夜などの飲酒が自然に想定されるタイミング：高リスク

    【4. 人数構成と科目の不整合】

    - 自社参加人数が多い（4人以上）かつ高額申請（アルコール費用を含む可能性）：高リスク
    - 他社参加なしにもかかわらず「接待交際費」となっている：高リスク

    【5. 曖昧な表現やイベント性】

    - 「情報交換」「今後の関係構築」「労い」「親睦」「送別会」「歓迎会」など、酒席を連想させるイベント用語が使われている

    【6. 申請タイミング・原本の有無】

    - 領収書の発行時間と申請時間に大きなズレがある（記憶が曖昧な可能性）

    ---

    以上の情報を総合的に判断し、以下のルールで出力してください：

    - **明示的にアルコール関連と判断できる、または社会常識的に高確率で提供されると考えられる場合** → `高リスク`
    - ★★支払先訪問先がスーパー、コンビニの場合★★ →　`中リスク`
    - **アルコールが提供された可能性が極めて低い、または判断が困難である場合** → `低リスク`

    【出力形式】

    - 判定結果（低リスク or 中リスク　or 高リスク）：
    - 判定理由（150文字以内）：
    - 経費ID（{{ $json['経費ID'] }}）

    入力データは以下のように与えられます。

    経費ID：{{ $json['経費ID'] }}
    申請日：{{ $json['申請日'] }}
    利用日：{{ $json['利用日'] }}
    支払先訪問先：{{ $json['支払先訪問先'] }}
    経費科目：{{ $json['経費科目名'] }}
    借方勘定科目：{{ $json['借方勘定科目'] }}
    金額：{{ $json['税込金額'] }}
    自社参加人数：{{ $json['自社参加人数'] }}
    他社参加人数：{{ $json['他社参加人数'] }}
    メモ：{{ $json['メモ'] }}
    目的：{{ $json['目的'] }}


💡　条件式、

- 懇親会」「親睦」「打ち上げ」などの語句がある → 高リスク
- 支払先が飲食店やスーパー・コンビニの場合 → 高〜中リスク
- 金曜夜や土曜夜など、飲酒が自然な曜日での申請 → 高リスク
- 「接待交際費」なのに他社がいない or 参加人数が多すぎる → 高リスク
- 「情報交換」「顔合わせ」など曖昧な表現 → 中リスク
</aside>

## ■判定例／サンプル

<aside>
💡

実行結果として出力される監査理由の例

中リスク：

支払先が「ライフ」というスーパーであり、アルコール飲料の購入が可能な場所であるため、アルコールを含む可能性がある。ただし、メモや目的にアルコールを示唆する記載はない。

中リスク：

支払先がコンビニ（LAWSON）であり、経費科目が「会議費」となっているため、アルコールが含まれる可能性は中程度。ただし、目的が「軽食」となっているため、アルコールの可能性は低いが完全には排除できない。

</aside>
